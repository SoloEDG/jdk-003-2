# 余烬行旅

安装依赖：`npm install`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose -p pinru-jdk003-high-1113 up --build -d`，访问 http://localhost:18023。

停止：`docker compose -p pinru-jdk003-high-1113 down`。

## 远征契约

进入新地区时，路线面板下方会出现一份三选一的远征契约（也可放弃，放弃不产生任何进度）。
契约给出明确目标（如“不移除攻击牌，并在三场战斗内用中毒击败两名敌人”）、期限与约束。

- 牌组调整、商店交易与战斗结束都更新同一份契约进度；只有实际提交的行为计数，预览与取消不计数。
- 战斗结束的奖励页会列出本次结算依据（每个增量与判定原因），解释“这次为何算数 / 为何违约”。
- 有效契约会在商店上架专属货物；违约或失效后未购买的专属库存立即撤下，已买到的卡仍归玩家所有。
- 违约会冻结失败原因并写入契约台账；跨区时未完成的契约先判失效，再生成新地区的契约。
- 进度与领奖状态随存档保存恢复：事件去重保证不重复累计，完成报酬只发放一次。

类型检查：`npm run typecheck`；生产构建：`npm run build`。

行为验证脚本（项目外，通过 Vite SSR 加载真实模块）：

```
node /workspace/contract-tests/run.mjs
```
